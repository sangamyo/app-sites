3. Shared care circles

A care circle has up to six members. Anyone who joins with your invite code can see and edit all of the circle's costs, payments and tasks. Only share the code with family members you trust. You can rotate the code or leave the circle at any time. If you leave, the costs and payments you took part in stay in the family's ledger so everyone's balances still add up.
